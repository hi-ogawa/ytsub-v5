# Zamak

A Chrome extension and a web app for learning languages from YouTube subtitles. Watch a video with two subtitle tracks side by side, bookmark words and phrases, and review them later on any device.

- Web app: https://zamak.hiro18181.workers.dev/
- Extension: https://chromewebstore.google.com/detail/zamak/gkonhebhbkfoeggebiipfbblfecdbabn
- Extension canary build from `main`: https://github.com/hi-ogawa/ytsub-v5/releases/download/extension-canary/zamak-extension.zip (unzip and load with Load unpacked in `chrome://extensions`)
