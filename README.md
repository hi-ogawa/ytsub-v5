# Zamak

A web app and a browser extension for language learning via YouTube subtitles. Watch videos with dual subtitle panel, bookmark words/phrases, and build vocabulary.

- Web app: https://zamak.hiro18181.workers.dev/
- Extension: https://chromewebstore.google.com/detail/zamak/gkonhebhbkfoeggebiipfbblfecdbabn

## Development

```bash
pnpm install
pnpm db:bootstrap

# Web app: http://localhost:5173/
# Extension: load dist/extension-dev as unpacked extension in Chrome
pnpm dev-full
```
