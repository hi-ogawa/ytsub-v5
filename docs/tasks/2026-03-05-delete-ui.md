# Delete UI for Videos and Bookmarks

## Status: Planning

## Problem

Backend `deleteVideo` and `deleteBookmark` oRPC endpoints exist but there's no UI to trigger them.

## Context

- **Video list page:** `src/routes/video-list.tsx` — grid of video cards, each wrapped in `<Link>`
- **Bookmark list:** `src/routes/video-viewer.tsx` `BookmarksList` (lines 199-246) — list of bookmark items in viewer's right panel
- **Backend endpoints:** `src/server/routes/videos.ts` `deleteVideo`, `src/server/routes/bookmarks.ts` `deleteBookmark`
- **Mutation pattern:** `useMutation(orpc.<route>.mutationOptions({ onSuccess }))` (see `src/routes/login.tsx`, `src/app.tsx`)
- **No component library** — plain Tailwind + HTML elements
- **No existing confirmation dialog** — need to establish pattern

## Approach

### 1. Video delete button

In `src/routes/video-list.tsx`:

- Add a delete button (trash icon or "X") on each video card
- `e.preventDefault()` + `e.stopPropagation()` to prevent navigation via the `<Link>` wrapper
- On click, `window.confirm` with video title
- On confirm, call `orpc.videos.deleteVideo` mutation
- On success, invalidate `videos.listVideos` query

### 2. Bookmark delete button

In `src/routes/video-viewer.tsx` `BookmarksList`:

- Add a delete button (trash icon or "X") on each bookmark row
- `e.stopPropagation()` to prevent seek-to-timestamp behavior
- On click, `window.confirm`
- On confirm, call `orpc.bookmarks.deleteBookmark` mutation
- On success, invalidate `bookmarks.listBookmarks` query

## Implementation steps

1. Add delete button + mutation to video list page
2. Add delete button + mutation to bookmark list
3. Verify with `pnpm tsc && pnpm lint` and `pnpm build`
