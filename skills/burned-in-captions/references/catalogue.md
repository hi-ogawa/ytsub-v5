# Catalogue of Caption Patterns

Each row pairs a feature signature with what it usually means. The signatures are rough, because they come from a few channels, so when the frames show something else, trust the frames. The keys are in [Features](../SKILL.md#features). With regions set, read `kept`, `gone`, and `new` as the region's keys, and a cluster as a region.

| Pattern                                  | Feature signature                                                                                                                                                                  | Usually means                                                                                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Swap                                     | `kept` drops, `gone` and `new` both high                                                                                                                                           | one caption replaced another. A late frame on each side reads both.                                                                 |
| Swap in the same spot and size           | `gone` and `new` spike far above the steps around them while `scene` stays low. `kept` may drop clearly or barely, depending on how much of the new text lands on the old letters. | a new caption in the old one's place, which `kept` alone can miss. Read both sides of the spike.                                    |
| Reveal or typing                         | `new` grows while `gone` stays near zero and `kept` stays high                                                                                                                     | a line appearing part by part. The run's last frame shows the whole line.                                                           |
| Crossfade                                | `kept_1s` and `kept_2s` fall slowly while `kept` stays high, with no swap in the 1–2 s before                                                                                      | one caption fading into another. A frame after the fade settles reads the new one.                                                  |
| Fade in or out                           | `letters` ramps up or down over 1–2 steps                                                                                                                                          | a caption fading. Frames on the ramp show partial text. A read that lands on one comes back noted, and merges with the steady read. |
| Caption holds across a camera cut        | `scene` spikes, but the region's `kept` stays high, or the clusters stay put                                                                                                       | the same caption over a new shot, so it needs no new read.                                                                          |
| Side caption with the main one           | two regions or clusters with independent change times                                                                                                                              | separate captions, each read when it changes.                                                                                       |
| Commentary that stays while lines change | one cluster holds while another swaps                                                                                                                                              | a held caption next to changing lines, so the held text is read once.                                                               |
| Scrolling line                           | whole-frame `kept` stays near half at every step for several seconds while `scene` stays low, with `gone` and `new` both large and about equal                                     | a large line moving across the frame. Each frame shows only a fragment, so read every other step and piece the line together.       |
| Scenery as text                          | whole-frame `letters` stays in the thousands with no caption, `kept` drops at every camera cut, and clusters move with the scene                                                   | the masks are reading scenery. Regions around the caption areas fix it.                                                             |
